==================
last-pypi-version
==================

-----------------------------------------------------
print the latest released version of a PyPI package
-----------------------------------------------------

:Author: David Villa Alises
:date:   2026-08-04
:Manual section: 1

SYNOPSIS
========

``last-pypi-version`` <package-name>

DESCRIPTION
===========

``last-pypi-version`` queries the PyPI JSON API for *package-name* and
prints the highest released version number to standard output.

See https://bitbucket.org/DavidVilla/ian/src/tip/README.rst
